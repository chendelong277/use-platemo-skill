# use-platemo-skill

A skill package for Claude Code to efficiently work with the local PlatEMO MATLAB platform.

## What is this?

This is a skill for Claude Code that helps the AI assistant work more effectively with PlatEMO - a MATLAB platform for evolutionary multi-objective optimization. It provides:

- Guidance on PlatEMO's entry points and file structure
- Instructions for running benchmark and user-defined problems
- Source code navigation for algorithms, problems, metrics, and GUI
- Best practices for working with PlatEMO's evolving codebase

## Installation

See `use-platemo-skill-guide.txt` for detailed installation instructions.

Quick install:
```bash
unzip use-platemo-skill.zip
cp -r use-platemo ~/.claude/skills/
```
